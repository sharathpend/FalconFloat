## FalconFloat

**Paper**: FalconFloat: An Open-Source, Specialized Floating-Point Unit for FALCON Signature Generation on FPGA

**Conference**: Proceedings of the 2026 International Conference on Field Programmable Technology (ICFPT), December 7-10, 2026, Honolulu, Hawaii, USA.

## Using the units

Each unit in `rtl/` is a standalone module with its own testbench, and they are meant to be picked individually and connected for your own FALCON schedule. `fpr_top` wraps them together for convenience and testing, but it is not tuned for any particular FALCON implementation. See [HOW_TO_USE_README.md](HOW_TO_USE_README.md) for the tools, the testbenches and the module parameters.
